Подтверждённый мониторинг через GitHub Actions

Вместо режима no-cors сервер GitHub сам проверяет HTTP-код и сохраняет результат в репозитории. Проверяем связь с GitHub... Облачная проверка работает без открытого браузера после настройки Actions и Pages. Браузерные запросы каждые 30 секунд выполняются только при открытой вкладке, а без CORS браузер не может прочитать их HTTP-статус. Сервис Render всё равно может перезапуститься или достичь лимитов Free.
